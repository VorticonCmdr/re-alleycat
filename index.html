Alley Cat browser port

Runs your own copy of the original 1984 IBM PC game. Nothing is uploaded: the file stays in this browser.

Controls & settings
  • Arrow keys (or numeric keypad incl. diagonals 7 9 1 3) move the cat; Alt performs special actions; Esc pauses.
  • Ctrl+S sound, Ctrl+R restart, Ctrl+M menu (also the buttons above).
  • Gamepad: stick/D-pad moves, A = Alt, Start = Esc, Select = Space. Answer “Y” to the joystick question to use the original's joystick mode instead.

Changing the machine restarts the game. Only the DOSBox reference machine is verified against the original.

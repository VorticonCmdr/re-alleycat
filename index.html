Alley Cat browser port

Runs your own copy of the original 1984 IBM PC game. Nothing is uploaded: the file stays in this browser.

Controls
  • Arrow keys (or numeric keypad incl. diagonals 7 9 1 3) move the cat.
  • Alt performs special actions. Esc pauses.
  • Ctrl+S sound, Ctrl+R restart, Ctrl+M menu (also available as buttons, since browsers reserve some Ctrl shortcuts).
